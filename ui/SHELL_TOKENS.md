# Shell 约定（第二轮）

## 活力蓝
- `--accent: #2563eb`
- `--accent-soft: #dbeafe`（选中底加深一档）
- 侧栏图标默认品牌蓝；选中左侧 **4px** 指示条
- 标题栏底边 **1px** 蓝线
- `--bg-console: #f8faff` 日志底与主区分层

## 交互确认
| 项 | 行为 |
|----|------|
| 窗口控件 | 右上：主题 / 最小化 / 最大化 / 关闭；`no-drag` |
| 拖拽区 | 仅标题栏左侧空白 `drag` |
| 侧栏折叠 | **底部**「折叠侧栏」按钮（状态胶囊上方） |
| 日志 | **默认折叠**；顶部细条 **拖高度**；`error` **自动展开** |
| 主题 | 标题栏蓝图标循环 system → light → dark |
